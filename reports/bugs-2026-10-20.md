## BUG-01 — ✅ FIXED (backend `15fdbf1b`), keep for history

**Title:** `[Bug][Follow Requests - Chat] Admin chat timeline returns 404 for every chat that contains a quotation`
**Priority:** Critical

**Paths**
* Frontend: `src/app/shared/components/chat/hooks/useChatTimeline.ts` → `GET /admin/chats/{id}`
* Backend: `routes/api/v1/admin.php:64` (unnamed route), `app/Http/Resources/Common/TimelineItemResource.php:61`

**Functional Requirements (Fix Requirements)**
* The admin chat timeline on the follow-request details page must load for every request, including requests that have quotations.
* `route("admin.quotations.print")` must resolve. Name the admin route `->name('quotations.print')`, the same way the client and provider route files already do.
* Server-side exceptions must not be returned as `404 غير موجود`. A routing or code error should return 500 so it gets noticed.

**Error Details Table**
| Affected Element/Field | Error Type | Current Impact | Required Fix |
| :--- | :--- | :--- | :--- |
| `GET /api/v1/admin/chats/{id}` | Backend exception (`RouteNotFoundException: Route [admin.quotations.print] not defined`) | API returns `404 "غير موجود"`. The chat panel on the follow-request details page is empty for every request past "pending" (all requests with a quotation). | Add `->name('quotations.print')` to `Route::post('quotations/print', ...)` in `admin.php`. |
| `TimelineItemResource::offer_document` | Missing named route for the admin prefix | Every quotation card in the timeline crashes the whole response. | Keep `route("{$prefix}.quotations.print")` and register the admin name. |
| Exception handler (`exceptionError`) | Wrong status mapping | Real 500 errors are reported as 404 "not found", which hides the bug. | Map non-`ModelNotFound` exceptions to 500. |
